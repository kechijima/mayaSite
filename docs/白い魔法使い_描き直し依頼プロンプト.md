・他のキャラクター（添付の青い猿・赤い竜を参照）と比べて、顔が小さく、位置が低い。

1. 画像の一番上＝帽子の先、一番下＝靴の底。上下に余白を作らない。

   帽子のデザイン自体（形の印象・装飾）は変えないでください。
4. 背中の翼と裾は、今より横に広げず、全身のシルエットを縦長に保ってください。

【納品仕様】

・サイズは 1280×1850 ピクセル以上
